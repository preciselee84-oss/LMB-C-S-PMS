# 청구자료 메뉴

## 메뉴 개요

`청구자료` 메뉴는 통합CMS 고객의 개설, ERP 연계, 로그인 실적, 구독정보, 고객명단 정보를 대사하여 월별 청구자료를 생성하고 검증하는 관리 메뉴입니다.

청구 대상 고객을 수작업으로 취합하는 대신 업로드 파일과 구글 시트 데이터를 기준으로 청구 원본을 확인하고, 개설 청구자료와 연계 청구자료를 엑셀로 다운로드할 수 있도록 구성합니다.

## 메뉴 목적

- 개설 및 ERP 연계 청구 대상 고객 확인
- 은행 로그인 실적과 청구 원본 데이터 대사
- CRM 구독정보와 통합CMS 고객명단 기준의 고객 정보 보강
- 청구구분, 해지 여부, 로그인 실적을 반영한 청구자료 생성
- 월별 청구 기준으로 개설/연계 청구 현황 다운로드

## 메뉴 구성

### 1. 청구자료 생성

`청구자료 생성` 화면은 청구 원본 파일과 은행 로그인 실적파일을 업로드하여 청구자료 생성 전 확인 목록을 만드는 화면입니다.

주요 기능:

- 은행 로그인 실적파일 업로드
- 구축 및 연계 리스트 업로드
- CRM 구독정보 파일 업로드
- 통합CMS 고객명단 파일 업로드
- 개설 청구자료 생성 대상 확인
- 연계 청구자료 생성 대상 확인
- 청구자료 엑셀 다운로드

지원 파일 형식:

```text
.xlsx
```

### 2. 청구자료 작성

`청구자료 작성` 화면은 하나은행 구글 시트와 하나은행 청구 시트를 고객번호 기준으로 대사하여 월별 개설/연계 청구 현황을 생성하는 화면입니다.

주요 기능:

- 청구자료 생성용 구글 시트 조회
- 청구 기준월 선택
- 개설 대상 건수 확인
- 연계 대상 건수 확인
- 청구 시트 누락 고객 확인
- 선택한 청구 기준월의 청구자료 다운로드

## 업로드 파일

### 은행 로그인 실적파일

은행에서 제공하는 통합CMS 로그인 실적파일입니다.

활용 기준:

- 최초 로그인 일자 확인
- 최종 로그인 일자 확인
- 로그인 횟수 확인
- 메뉴 클릭 수 확인
- 개설 및 연계 청구 대상의 실제 사용 여부 확인

### 구축 및 연계 리스트

개설 실적과 ERP 연계 실적이 포함된 청구 원본 파일입니다.

활용 기준:

- 개설 청구 대상 추출
- ERP 연계 청구 대상 추출
- 고객번호, 사업자번호, 업체명 기준 대사
- 접수일자, 구축일자, 방문일자, 연계시작일자 확인

### CRM 구독정보 파일

HANA사업부 고객관리 CRM의 구독정보 파일입니다.

활용 기준:

- 고객번호 및 사업자번호 보강
- 고객명 기준 참고 정보 매칭
- 청구 원본의 누락 정보 보완
- 청구 대상 고객의 구독 상태 확인

### 통합CMS 고객명단 파일

은행 통합CMS 고객명단 파일입니다.

활용 기준:

- 고객번호 기준 청구구분 대사
- 사업자번호 기준 청구구분 대사
- 고객명 기준 보조 매칭
- 청구구분 누락 데이터 보강

## 데이터 대사 기준

청구자료는 아래 우선순위로 고객 정보를 대사합니다.

1. 고객번호
2. 사업자번호
3. 업체명 또는 고객명
4. CRM 구독정보 참고값
5. 통합CMS 고객명단 참고값

대사 결과는 개설 청구자료와 연계 청구자료에 각각 반영됩니다.

## 개설 청구자료

개설 청구자료는 통합CMS 구축 고객을 기준으로 생성합니다.

주요 확인 항목:

- 고객번호
- 사업자번호
- 업체명
- ERP 연계 여부
- 해지체크
- 접수일자
- 구축일자
- 방문일자
- 담당자
- 최초 로그인
- 최종 로그인일자
- 로그인횟수
- 메뉴클릭수
- 청구구분

활용 목적:

- 구축 완료 고객의 청구 대상 여부 확인
- 구축 전 로그인 여부 확인
- 해지 또는 청구 제외 고객 확인
- 월별 개설 청구자료 생성

## 연계 청구자료

연계 청구자료는 ERP 연계 고객을 기준으로 생성합니다.

주요 확인 항목:

- 고객번호
- 사업자번호
- 업체명
- 해지체크
- 구분
- 추가연계신청일자
- 담당자
- 구축일
- 연계시작일자
- 은행연계완료일자
- 수령여부
- 최초 로그인
- 최종 로그인
- 로그인횟수
- 메뉴클릭수
- 청구구분

활용 목적:

- ERP 연계 완료 고객의 청구 대상 여부 확인
- 연계 시작일과 청구 기준월 확인
- 은행 연계 완료 여부 확인
- 월별 연계 청구자료 생성

## 청구자료 엑셀 다운로드

청구자료 생성 화면에서는 개설청구 건수와 연계청구 건수를 입력한 뒤 청구자료 엑셀 파일을 다운로드할 수 있습니다.

다운로드 파일명 형식:

```text
청구자료_YYYYMMDD_HHMMSS.xlsx
```

다운로드 파일에는 개설 청구자료와 연계 청구자료가 포함됩니다.

## 확인 및 주의사항

- 청구자료 생성 전 업로드한 파일의 기준월과 원본 작성 기준을 확인해야 합니다.
- 고객번호가 없거나 사업자번호가 다른 경우 고객명 매칭 결과를 반드시 확인해야 합니다.
- 해지 고객은 청구 대상에서 제외될 수 있으므로 해지체크 값을 확인해야 합니다.
- 최초 로그인일이 구축일보다 빠른 경우 청구 기준 검토가 필요합니다.
- 구글 시트를 불러오지 못하는 경우 환경설정의 Google Sheet URL과 접근 권한을 확인해야 합니다.
- 청구자료에는 고객번호, 사업자번호 등 민감한 고객 정보가 포함되므로 외부 공유 시 주의해야 합니다.

## 기대 효과

- 청구자료 작성 시간 단축
- 고객별 청구 누락 및 중복 청구 방지
- 개설/연계 청구 기준의 일관성 확보
- 은행 로그인 실적을 반영한 청구 검증 강화
- 월별 청구자료 산출 과정의 추적성 확보
