# 활동 이력 메뉴 안내

## 목적

`활동 이력` 메뉴는 본사 활동이력 파일을 업로드해 담당자별 월간 실적을 확인하고, 검증 오류를 점검한 뒤 최종 활동실적 엑셀과 실적보고서 PPT를 내려받거나 실적 결과를 전송하는 메뉴입니다.

## 사용 메뉴

`활동 이력`

## 준비 파일

1. 구독정보 파일
   - 예: `subscriptions_export (5).xlsx`
   - 지원 형식: `.xlsx`
   - `고객사명`, `사업자번호` 컬럼을 사용합니다.
   - 본사이력의 `회사` 컬럼과 매핑해 사업자번호를 자동 입력합니다.

2. 본사이력 파일
   - 예: `activities_export (5).xlsx`
   - 지원 형식: `.xlsx`
   - `회사`, `활동자`, `일시`, `유형`, `활동상세`, `활동구분`, `제목`, `내용` 등의 컬럼을 사용합니다.

3. 샘플 파일
   - 화면의 `샘플파일 다운로드` 버튼에서 내려받을 수 있습니다.
   - 최종 다운로드 양식 기준은 `LMB월간 활동실적__YYYYMM.xlsx` 형식입니다.

## 기본 사용 절차

1. 내부관리 CRM에 로그인합니다.
2. 좌측 메뉴에서 `활동 이력`을 선택합니다.
3. `구독정보 업로드`에 `subscriptions_export` 파일을 업로드합니다.
4. 화면에 `사업자번호 매핑 N건 준비` 메시지가 표시되는지 확인합니다.
5. `본사이력 업로드 (선택)`에 `activities_export` 파일을 업로드합니다.
6. `본사이력 업로드 데이터` 표에서 변환된 월간 활동실적 양식을 확인합니다.
7. 담당자별 활동 수치와 검증표를 확인합니다.
8. 오류가 없으면 `최종 실적 다운로드`, `실적보고서 PPT 다운로드`, `저장`, `실적 결과 전송`을 사용할 수 있습니다.

## 본사이력 업로드 데이터 표시 컬럼

업로드한 `activities_export` 파일은 아래 월간 활동실적 양식으로 표시됩니다.

| 순서 | 컬럼명 | 설명 |
|---:|---|---|
| 1 | 지사 | 기본값은 `HANA지사` |
| 2 | 상품 | 기본값은 `통합CMS` |
| 3 | 업체명 | `activities_export`의 `회사` 컬럼 우선 사용 |
| 4 | 사업자번호 | 구독정보의 `고객사명`과 회사명을 매핑해 입력 |
| 5 | 등록자 | 활동자 또는 담당자 |
| 6 | 활동일자 | 일시 또는 활동일자 |
| 7 | 방문장소 (시, 군, 구까지) | 방문장소, 주소, 지역 |
| 8 | 활동구분 | 방문, 원격, 상담 등 |
| 9 | 활동상세 | 개설, 연계, 운영 |
| 10 | 업무번호 | 업무번호, 플로우, 작성번호 |
| 11 | 제목 | 제목 또는 활동상세 기준 자동 제목 |
| 12 | 활동내역 | 내용, 활동내용, 처리내용 |

## 사업자번호 매핑 기준

- `subscriptions_export`의 `고객사명`과 `activities_export`의 `회사`를 비교합니다.
- 회사명 비교 시 공백, 일부 법인 표기, 특수문자를 정리한 뒤 매칭합니다.
- 이미 본사이력 파일에 사업자번호가 있으면 기존 값을 우선 사용합니다.
- 매칭되지 않은 행은 사업자번호가 빈칸으로 표시될 수 있습니다.

## 담당자별 활동 수치

화면에는 `웹케시 월간 실적 기준표`와 담당자별 실적 집계가 함께 표시됩니다.

| 활동구분 | 구분 | 고객당 점수 | 최대점수 (월) | 최대활동 |
|---|---|---:|---:|---|
| 기본활동 | 개설 | 90 | 1000 | - |
| 기본활동 | 연계 | 120 | 1000 | - |
| 기본활동 | 방문 | 30 | 1800 | 월 60회 |

담당자별 집계는 `개설`, `연계`, `운영` 기준으로 카운트됩니다.

## 검증 항목

업로드 후 아래 검증 항목을 확인합니다.

| 검증 항목 | 확인 내용 |
|---|---|
| 중복 이력 | 동일 사업자번호, 담당자, 활동일자, 활동상세 중복 여부 |
| 초과 방문 | 담당자별 하루 방문 6회 이상 여부 |
| 본사 개설완료일자 누락 | 개설 관련 실적의 본사 개설완료일자 누락 여부 |
| 본사 ERP연계일자 누락 | 연계 관련 실적의 본사 ERP연계일자 누락 여부 |
| 기타 오류 | 사업자번호, 본사 데이터 기준 추가 검증 오류 |

## 일별 5회 방문 초과 체크

`본사이력 업로드` 데이터가 있을 때 담당자별 일 방문횟수 표가 표시됩니다.

- 일 방문횟수가 6회 이상인 날짜는 빨간색으로 표시됩니다.
- 토요일과 일요일은 회색 음영으로 표시됩니다.
- 공휴일은 노란색 음영으로 표시됩니다.
- 공휴일 날짜는 `5/5(화/어린이날)`처럼 공휴일명이 함께 표시됩니다.
- 초과 방문 상세표에는 `요일`, `공휴일` 컬럼이 함께 표시됩니다.

## 이력 변경 추천 가이드

초과 방문이 있는 경우 `이력 변경 추천 가이드`가 표시됩니다.

- 6회 이상 방문일에서 초과된 건수를 계산합니다.
- 주말과 공휴일을 제외한 영업일 중 방문횟수가 5회 미만인 날짜를 추천합니다.
- 추천 가능한 날짜가 없으면 `여유 일자 부족`으로 표시됩니다.

## 다운로드 파일

`최종 실적 다운로드` 버튼을 누르면 월간 활동실적 양식으로 엑셀이 생성됩니다.

파일명 형식:

```text
LMB월간 활동실적__YYYYMM.xlsx
```

예:

```text
LMB월간 활동실적__202607.xlsx
```

## 실적 결과 전송

검증 오류가 없으면 `실적 결과 전송` 버튼이 활성화됩니다.

- 전송 대상은 현재 로그인한 담당자의 실적입니다.
- 전송 시각과 이력 작성월이 함께 저장됩니다.
- 검증 오류가 있으면 전송할 수 없으며, 먼저 오류 탭의 항목을 수정해야 합니다.

## 관리자 화면

관리자 모드에서도 같은 흐름으로 사용할 수 있습니다.

- `담당자 선택`에서 특정 담당자를 선택해 실적을 확인할 수 있습니다.
- `전체`를 선택하면 전체 담당자 실적 요약을 확인할 수 있습니다.
- 구독정보 업로드와 본사이력 업로드 방식은 일반 사용자 화면과 동일합니다.

## 주의사항

- `구독정보 업로드`를 먼저 진행한 뒤 `본사이력 업로드`를 진행해야 사업자번호 매핑이 가장 정확합니다.
- 본사이력 파일을 먼저 업로드한 뒤 구독정보 파일을 올려도 기존 업로드 데이터의 빈 사업자번호는 다시 보강됩니다.
- 본사 구글시트 연결이 실패해도 업로드 데이터 표와 기본 실적 계산은 계속 진행됩니다.
- 최종 다운로드 파일은 화면에 표시되는 월간 활동실적 양식을 기준으로 생성됩니다.
