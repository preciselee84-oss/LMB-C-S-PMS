# 이력 템플릿 변환 툴 안내

## 목적

은행/핫라인 활동이력 파일을 본사 공유용 `activities_template`의 `Activities` 시트 형식으로 변환합니다.

## 사용 메뉴

`이력 템플릿 변환`

## 준비 파일

1. 원본 활동이력 파일
   - 예: `202607활동이력(07-08).xls`
   - 지원 형식: `.xls`, `.xlsx`

2. 변환 기준 템플릿 파일
   - 예: `activities_template (9).xlsx`
   - 지원 형식: `.xlsx`
   - 템플릿 안에 `Activities` 시트가 있어야 합니다.

## 변환 절차

1. 내부관리 CRM에 로그인합니다.
2. 좌측 메뉴에서 `이력 템플릿 변환`을 선택합니다.
3. 왼쪽 업로드 영역에 원본 활동이력 파일을 업로드합니다.
4. 오른쪽 업로드 영역에 `activities_template` 파일을 업로드합니다.
5. 두 파일이 모두 업로드되면 자동으로 변환이 진행됩니다.
6. 화면에서 변환 결과 미리보기를 확인합니다.
7. `변환 파일 다운로드` 버튼을 눌러 결과 파일을 내려받습니다.

## 출력 파일

다운로드 파일명은 아래 형식으로 생성됩니다.

```text
activities_template_converted_YYYYMM.xlsx
```

예:

```text
activities_template_converted_202607.xlsx
```

## 주요 변환 항목

| 템플릿 컬럼 | 입력 기준 |
|---|---|
| 유형 | 원본의 접수유형/활동유형/유형 기준 |
| 제목 | 요청사항, 처리내용, 업무유형 기준 자동 생성 |
| 일시 | 접수일자 + 접수시간 기준 |
| 활동자 | 담당자 또는 접수자 |
| 회사명 | 업체명/회사명/고객명/상호 |
| 고객사명 | 회사명과 동일 |
| 사업자번호 | 고객번호 기준 구글 시트 매핑 |
| 관련제품 | CMS구분/제품/상품, 없으면 통합CMS |
| 활동내역 | 처리내용 또는 요청사항 |
| 활동 상세 | 운영 |
| 활동 구분 | IN |
| 팀구분 | HOTLINE |

## 필수 확인 컬럼

원본 파일에서 아래 컬럼을 찾지 못하면 변환이 중단됩니다.

| 필수 항목 | 인식 컬럼 예시 |
|---|---|
| 접수일자 | 접수일자, 일자, 날짜 |
| 업체명 | 업체명, 회사명, 고객명, 상호 |
| 담당자 | 담당자, 활동자 |
| 내용 | 요청사항, 문의내용, 접수내용, 처리내용, 활동내역, 조치내용 |

## 사업자번호 매핑

- 원본 활동이력의 고객번호를 기준으로 구글 시트의 사업자번호를 찾아 입력합니다.
- 매핑에 실패한 건은 `사업자번호`가 빈칸으로 저장됩니다.
- 변환 완료 후 화면에 매핑 실패 건수가 표시되면, 다운로드 파일에서 해당 행의 사업자번호를 확인해야 합니다.

## 오류 메시지별 조치

| 메시지 | 조치 |
|---|---|
| 원본 활동이력 파일과 변환 기준 템플릿 파일을 모두 업로드해주세요. | 두 파일을 모두 업로드합니다. |
| 변환할 데이터가 없습니다. | 원본 파일의 첫 번째 시트에 활동이력 데이터가 있는지 확인합니다. |
| 원본 파일에서 특정 컬럼을 찾을 수 없습니다. | 필수 확인 컬럼명이 원본에 있는지 확인합니다. |
| xls 파일 변환을 위해 xlrd 패키지가 필요합니다. | 실행 환경에 `xlrd` 패키지를 설치해야 합니다. |
| 변환 중 오류가 발생했습니다. | 파일 형식, 시트명, 템플릿의 `Activities` 시트를 확인합니다. |

## 공유 전 확인 사항

1. 변환 결과 미리보기에서 활동자, 일시, 회사명, 활동내역이 정상인지 확인합니다.
2. 사업자번호 매핑 실패 건이 있으면 다운로드 파일에서 보완합니다.
3. `Activities` 시트의 헤더가 본사 제공 템플릿과 동일한지 확인합니다.
4. 변환 파일은 원본 파일을 수정하지 않고 새 파일로 다운로드됩니다.
