# A
AX-Wetak 360 · 위탁 사업장 지급 관리 플랫폼

**개념과 방향**
위탁 사업장의 전도금 요청부터 지급 확정, 사용 보고까지 전 과정을 한 화면에서 끊김 없이 처리합니다.
**We**는 웹케시(Webcash)의 We, **360**은 전도금 요청 → 전자결재 → 이체 확정 → 사용 보고에 이르는 360도 빈틈없는 사이클을 의미합니다.

---

## 1 배경 — 왜 만드나

위탁 사업장에 전도금을 지급하는 과정이 메일·메신저·엑셀로 분산되어 있어,
승인 지연·이중 지급·증빙 누락 같은 문제가 반복되었습니다.
핵심 목표는 **"요청→결재→이체→정산 사이클을 단일 시스템 안에 묶어, 담당자 없이도 흐름이 멈추지 않게 하는 것"** 입니다.

| ✅ | **전자결재** — 관리자가 요청 건을 승인하거나 반려 사유를 남겨 처리합니다. | 현재 |

| 🏦 | **이체 자료 확정** — 품의 확정 건을 선택해 출금계좌를 지정하고 이체자료(엑셀)를 생성합니다. | 현재 |
| 💸 | **지급 결과 확인** — 이체 대상 건의 입금 대사를 확인하고 이체 완료를 확정합니다. | 현재 |
| 🧾 | **전도금 사용 결의 보고** — 이체 완료 후 사용 내역을 항목별로 작성하고 증빙을 첨부해 결재 요청합니다. | 현재 |
| 💼 | **계좌 잔고 확인** — 위탁 사업장 계좌의 잔고·거래내역을 기간·내용 필터로 조회합니다. | 현재 |
| 📊 | **대시보드** — 결재 대기·품의 확정·이체 완료 건수를 한눈에 보고 AI 인사이트를 확인합니다. | 현재 |
| 🏢 | **위탁 사업장 관리** — 사업장 정보, 계좌, 담당자를 등록·수정합니다. | 현재 |
| 📑 | **계좌 원장 조회** — 은행 원장 기반 시재 확인 및 이상거래 탐지(FDS). | 확장 |

## 3 어떻게 동작하나 — 전체 흐름

전도금 지급은 아래 5단계 사이클로 완결됩니다.
각 단계마다 담당자·관리자·시스템 역할이 명확히 나뉩니다.

```
① 위탁사업장 담당자          ② 관리자(전자결재)
   전도금 요청 등록    ──→    승인 / 반려 처리
                              ↓ 승인 시 "품의 확정"

③ 관리자(지급 관리)          ④ 관리자(지급 관리)
   이체 자료 확정     ──→    이체 완료 확인
   (출금계좌 선택·         (입금 대사 / 수기 확인)
    엑셀 다운로드)           ↓ "이체 완료" 전환

⑤ 위탁사업장 담당자
   전도금 사용 결의 보고
   (사용 내역 작성 + 증빙 첨부 → 전자결재 재요청)
```

**상태 흐름**
`요청` → `품의 확정` → `이체 대상` → `이체 완료`
(반려 시 → `반려`, 사용보고 결재 시 → `승인` / `반려`)

---

## 4 핵심 흐름 — 이체 자료 확정과 지급 확인

이체 단계는 두 화면이 연결됩니다.

**이체 자료 확정 (관리자)**
- 품의 확정 건 목록에서 이체할 사업장을 선택(체크박스)
- 출금 계좌 선택(메인 계좌 우선 표시)
- 예금주 조회 후 입금통장표시·출금통장표시 입력
- "이체 자료 확정" 클릭 → 상태 "이체 대상" 전환 + 엑셀 다운로드
- 확정 후에도 하단에 "이체 자료 확정 건" 목록이 유지되어 이중 처리를 방지합니다.

**지급 결과 확인 (관리자)**
- 이체 자료 확정 시 저장된 정보(은행·계좌·예금주·통장표시)가 그대로 표시
- 입금 대사 결과(계좌번호·금액 일치 여부) 자동 확인
- 체크박스로 다건 선택 → "선택 건 이체 완료 확인" 일괄 처리
- 이체 완료 이력은 하단 표에서 영구 조회 가능

## 5 어떤 데이터를 어떻게 활용하나

| 저장 파일 | 주요 데이터 | 활용 |
|---|---|---|
| `delegated_workplaces.json` | 사업장 정보, 전도금 요청 & 상태 | 요청·결재·이체 전 사이클 |
| `approvals.json` | 전자결재 문서 (전도금요청 / 사용품의서) | 결재 이력·승인자·반려사유 |
| `bank_accounts.json` | 위탁사업장 계좌, 잔고, 거래내역 | 이체 자료 생성, 잔고 확인 |
| `usage_reports.json` | 사용 결의 보고 항목, 첨부 증빙(base64) | 전도금 사용 내역 결재 |
| 회사 프로필 (company profile) | 출금 계좌(메인 포함), 회사 기본정보 | 이체 자료 출금계좌 선택 |
| MSSQL (서버 접속 정보) | 업무 DB — 사용자 정의 SELECT | 잔고 조회·스케줄 연동(확장) |

**권한 구분**
- `관리자` — 전체 메뉴 접근, 전자결재 처리, 이체 자료 확정·지급 확인
- `일반 사용자(담당자)` — 위탁 사업장 섹션만 접근 (전도금 요청 / 품의 결과 / 사용보고 / 계좌 잔고)

## 6 방향 — 단계적 진행

**현재 (완성)**
- 전도금 요청 → 전자결재 → 이체 자료 확정 → 지급 결과 확인
- 전도금 사용 결의 보고 + 증빙 첨부
- 위탁 사업장·계좌·담당자 관리
- 계좌 잔고·거래내역 조회
- 대시보드 + AI 인사이트

**다음 (예정)**
- 입금 대사 자동화 (은행 API 연동)
- 텔레그램 / 카카오 알림 (결재 요청·이체 완료 즉시 발송)
- MSSQL 연동 — 스케줄 이행 여부 자동 점검

**확장 (검토)**
- 계좌 원장 기반 시재 확인 및 FDS (이상거래 탐지)
- 다기관 멀티 테넌트 (법인 단위 분리)
- 보고서 자동 생성 (월별 지급 현황 PDF·엑셀)
