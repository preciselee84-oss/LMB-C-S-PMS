# 작업 내역 (2026-06-15)

## 1. 페이지 상단 타이틀 정리
- `render_page_title()`에서 모든 메뉴 공통으로 상단 HOME 버튼과 `## {메뉴명}` 가운데 제목을 제거.

## 2. 사용품의서 보고 메뉴 추가 (위탁 사업장)
- 위탁 사업장 섹션에 "사용품의서 보고" 메뉴 신설.
- 이체 완료된 전도금 요청을 선택해 사용내역(사용일자/품목명/금액/비고)을 `data_editor`로 다건 입력.
- 영수증/증빙 파일 첨부(`st.file_uploader`, base64 저장).
- 제출 시 전자결재로 결재 요청(`doc_type="사용품의서"`) 전달, 처리 결과는 사용품의서 현황에서 확인.
- `usage_reports.json` 신규 데이터 파일 및 `_load_usage_reports`/`_save_usage_reports` 헬퍼 추가.
- 전자결재(`show_e_approval`)에 "사용품의서" 문서 타입 승인/반려 분기 추가.

## 3. 이체 자료 확정 (구 "이체 자료 생성") 개편
- 메뉴명 "이체 자료 생성" → "이체 자료 확정"으로 변경 (사이드바, 가이드, 라우팅, AI 인사이트 메시지 전체 반영).
- "이체 대상 선택" 표를 정보 표 + 편집 표로 나뉘어 있던 것을 **하나의 표**로 통합.
  - 컬럼 순서: 선택, 사업장명, 입금은행, 입금계좌번호, 입금액, 예상예금주, 조회한예금주, 입금통장표시, 출금통장표시
  - 각 컬럼 width를 small로 지정해 한 줄에 표시.
- "이체 자료 확정" 버튼 옆에 "📥 엑셀 다운로드" 버튼 추가(선택 현황 기준으로 즉시 다운로드 가능).
- 이체 자료 확정 후에도 해당 건이 화면에서 사라지지 않도록, 하단에 "이체 자료 확정 건" 표를 별도로 표시(사업장명/입금은행/입금계좌번호/입금액/이체자료확정일시).
- 확정 시 입력했던 예상예금주/조회한예금주/입금통장표시/출금통장표시 값을 요청 데이터에 저장하여 이후 단계에서도 동일하게 표시되도록 함.

## 4. 지급 결과 확인 개편
- "이체 대상" 목록을 카드형 → **표 형식**으로 변경.
  - "이체 자료 확정"의 이체 대상 선택 표와 동일한 컬럼 구성(선택, 사업장명, 입금은행, 입금계좌번호, 입금액, 예상예금주, 조회한예금주, 입금통장표시, 출금통장표시)으로 통일.
  - 체크박스로 다건 선택 후 "선택 건 이체 완료 확인" 버튼으로 일괄 "이체 완료" 처리.
- (추가 후 제거) 이체 결과 엑셀 업로드 자동 매칭 기능 — 요청에 따라 최종적으로 제거하고 표 기반 일괄 확인 방식만 유지.

## 5. 시스템 명칭 변경: AX-Wetak 360
- "위탁사업장 관리 시스템" 표기를 "AX-Wetak 360"으로 변경.
  - 브라우저 탭 제목(`st.set_page_config`)
  - 로그인 화면 로고 타이틀
  - 사이드바 브랜드 타이틀 및 브랜드 마크("S" → "AX")
  - 서버 접속 정보(MSSQL) 화면 설명 문구
- 명칭 의미: **A**X-**We**tak (웹케시의 "We") **360**(360도 빈틈없이 관리).

## 기타
- 모든 변경 사항은 `python -m py_compile app.py` 컴파일 확인 및 `streamlit run` + HTTP 200 스모크 테스트 후 커밋/푸시 완료.
- 작업 중 남아있던 테스트용 streamlit 프로세스(8512~8546 포트)를 정리.
