# 활동이력 메뉴

## 메뉴 개요

`활동 이력` 메뉴는 내부관리 CRM에서 본사 활동이력 파일과 구독정보 파일을 업로드하여 담당자별 월간 활동실적을 확인하고, 오류 검증 후 최종 실적 파일과 실적보고서 PPT를 생성하는 메뉴입니다.

활동이력은 고객사 방문, 원격 지원, 상담, 개설, ERP연계, 운영 활동을 월간 실적으로 정리하기 위한 기준 데이터로 사용됩니다.

## 메뉴 목적

- 본사 활동이력 데이터를 월간 활동실적 양식으로 변환
- 구독정보와 매칭하여 사업자번호 자동 보강
- 담당자별 개설, 연계, 운영, 방문 실적 집계
- 중복 이력, 초과 방문, 필수 일자 누락 등 검증 오류 확인
- 최종 활동실적 엑셀 및 실적보고서 PPT 생성
- 검증이 완료된 실적 결과 전송

## 화면 구성

### 1. 구독정보 업로드

`subscriptions_export` 파일을 업로드하는 영역입니다.

주요 역할:

- 고객사명과 사업자번호 매핑 기준 생성
- 본사 활동이력의 회사명과 구독정보의 고객사명을 비교
- 매칭된 사업자번호를 활동실적 데이터에 자동 입력
- 기존 활동이력 파일에 사업자번호가 있으면 기존 값을 우선 사용

지원 형식:

```text
.xlsx
```

### 2. 사업자번호 매핑

구독정보 파일을 업로드하면 회사명 기준으로 사업자번호 매핑을 준비합니다.

매핑 기준:

- 공백 제거
- 일부 법인 표기 정리
- 특수문자 차이 완화
- 회사명 유사 매칭

매핑되지 않은 고객사는 사업자번호가 비어 있는 상태로 표시될 수 있습니다.

### 3. 본사이력 업로드

`activities_export` 파일을 업로드하는 영역입니다.

주요 역할:

- 본사 활동이력 데이터를 월간 활동실적 양식으로 변환
- 활동구분, 활동상세, 제목, 내용, 담당자, 활동일자 등을 기준으로 실적 분류
- 개설, 연계, 운영 활동을 담당자별로 집계
- 방문 활동은 일자별 방문 횟수 검증에 사용

지원 형식:

```text
.xlsx
```

### 4. 본사이력 업로드 데이터

업로드한 본사 활동이력을 월간 활동실적 기준 컬럼으로 표시합니다.

| 순서 | 컬럼명 | 설명 |
| ---: | --- | --- |
| 1 | 지점 | 기본값 또는 활동 기준 지점 |
| 2 | 상품 | 통합CMS |
| 3 | 업체명 | 본사이력의 회사명 |
| 4 | 사업자번호 | 구독정보 매핑 또는 원본 사업자번호 |
| 5 | 등록자 | 활동 담당자 |
| 6 | 활동일자 | 활동일 또는 일시 기준 일자 |
| 7 | 방문주소 | 방문 장소 또는 주소 |
| 8 | 활동구분 | 방문, 원격, 상담 등 |
| 9 | 활동상세 | 개설, 연계, 운영 등 |
| 10 | 업무번호 | 업무번호 또는 활동 식별 번호 |
| 11 | 제목 | 제목 또는 활동상세 기반 자동 제목 |
| 12 | 활동이력 | 내용, 활동내용, 처리내용 |

## 실적 집계 기준

### 개설

설치등록, 신규 개설, 사용자 등록 등 고객사 통합CMS 이용을 시작하기 위한 활동을 개설 실적으로 분류합니다.

### 연계

ERP연계, 테이블레이아웃, 데이터 반영, 내보내기, 연계 테스트 등 ERP 관련 활동을 연계 실적으로 분류합니다.

### 운영

로그인, 인증서, Agent, 서버점검, 이체, 조회, 오류 처리, 사용자 교육 등 일반 운영 문의와 지원 활동을 운영 실적으로 분류합니다.

### 방문

활동구분이 방문이거나 방문 주소가 확인되는 경우 방문 실적으로 집계합니다.

## 검증 항목

업로드 후 아래 검증 항목을 확인합니다.

| 검증 항목 | 확인 내용 |
| --- | --- |
| 중복 이력 | 동일 고객사, 담당자, 활동일자, 활동상세 중복 여부 |
| 사업자번호 누락 | 구독정보 매핑 실패 또는 원본 사업자번호 누락 여부 |
| 초과 방문 | 담당자별 하루 방문 횟수 초과 여부 |
| 개설 완료일자 누락 | 개설 관련 활동의 본사 개설완료일자 누락 여부 |
| ERP연계일자 누락 | 연계 관련 활동의 ERP연계일자 누락 여부 |
| 기타 오류 | 필수 컬럼 누락, 날짜 형식 오류, 데이터 공백 등 |

검증 오류가 있으면 최종 전송 전에 해당 항목을 수정해야 합니다.

## 일 5회 방문 초과 체크

본사이력 업로드 데이터가 있을 때 담당자별 일 방문횟수 표를 표시합니다.

- 하루 방문횟수가 6회 이상이면 초과 방문으로 표시
- 토요일과 일요일은 회색 영역으로 표시
- 공휴일은 별도 색상과 공휴일명으로 표시
- 초과 방문 상세표에는 요일, 공휴일, 방문건수, 활동 목록을 함께 표시

## 이력 변경 추천 가이드

초과 방문이 발생하면 가능한 대체 일자를 추천합니다.

추천 기준:

- 주말과 공휴일 제외
- 담당자별 방문 건수가 5건 미만인 날짜 우선
- 가능한 날짜가 없으면 사유를 표시

## 다운로드 기능

### 최종 실적 다운로드

검증 결과를 확인한 뒤 월간 활동실적 엑셀 파일을 생성합니다.

파일명 형식:

```text
LMB월간 활동실적__YYYYMM.xlsx
```

### 실적보고서 PPT 다운로드

월간 실적을 보고서 형태의 PPT로 생성합니다.

포함 내용:

- 담당자별 실적 요약
- 고객사별 활동 내역
- 주요 실적 지표
- 방문 및 운영 실적 집계

## 실적 결과 전송

검증 오류가 없으면 `실적 결과 전송` 버튼을 통해 현재 담당자의 실적 결과를 저장합니다.

전송 기준:

- 현재 로그인한 담당자 기준
- 검증 오류가 없어야 전송 가능
- 전송 시각과 작성월을 함께 저장
- 오류가 있으면 전송 전 수정 필요

## 관리자 화면

관리자 모드에서는 담당자별 실적을 조회할 수 있습니다.

주요 기능:

- 담당자 선택
- 전체 담당자 실적 확인
- 구독정보 업로드
- 본사이력 업로드
- 실적 집계 및 검증 결과 확인

## 사용 순서

1. 내부관리 CRM에 로그인합니다.
2. 좌측 메뉴에서 `활동 이력`을 선택합니다.
3. `구독정보 업로드`에 `subscriptions_export` 파일을 업로드합니다.
4. 사업자번호 매핑 준비 메시지를 확인합니다.
5. `본사이력 업로드`에 `activities_export` 파일을 업로드합니다.
6. 변환된 본사이력 업로드 데이터를 확인합니다.
7. 담당자별 활동 수치와 검증표를 확인합니다.
8. 오류가 있으면 원본 데이터 또는 입력값을 수정합니다.
9. 오류가 없으면 최종 실적 파일 또는 실적보고서 PPT를 다운로드합니다.
10. 필요한 경우 실적 결과를 전송합니다.

## 주의사항

- 구독정보 업로드를 먼저 진행한 뒤 본사이력 업로드를 진행해야 사업자번호 매핑이 가장 정확합니다.
- 본사이력 파일을 먼저 업로드한 뒤 구독정보 파일을 올려도 빈 사업자번호는 다시 보강됩니다.
- 본사 시스템 연결에 실패해도 업로드 데이터 기준의 기본 실적 계산은 진행됩니다.
- 최종 다운로드 파일은 화면에 표시되는 월간 활동실적 양식 기준으로 생성됩니다.
- 개인정보, 계좌정보, 인증정보 등 민감정보는 활동이력에 불필요하게 포함하지 않습니다.

## 기대 효과

- 본사 활동이력의 월간 실적 변환 자동화
- 담당자별 실적 확인 시간 단축
- 검증 오류 사전 확인으로 제출 품질 향상
- 사업자번호 매핑 자동화로 수기 보정 감소
- 실적보고서 작성 업무 간소화
