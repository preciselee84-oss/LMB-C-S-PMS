# 통합CMS 챗봇 메뉴

## 메뉴 개요

`통합CMS 챗봇`은 하나은행 통합CMS 운영 중 자주 발생하는 고객 문의와 처리 사례를 기반으로, 담당자가 빠르게 점검 방향과 답변 내용을 확인할 수 있도록 구성한 FAQ형 챗봇 메뉴입니다.

운영 담당자는 고객 증상이나 질문을 입력하면 유사 FAQ를 검색하고, 챗봇 화면에서 통합 처리결과와 유사 질문 후보를 함께 확인할 수 있습니다.

## 메뉴 목적

- 통합CMS 운영 문의에 대한 답변 속도 향상
- 로그인, 인증서, Agent, 서버점검, ERP연계, 설치등록 등 반복 문의 대응 표준화
- 활동이력, QNA, PPT 안내자료 등 기존 운영 자료를 FAQ 데이터로 축적
- 담당자별 답변 편차를 줄이고 고객 안내 품질 개선
- 신규 담당자가 과거 유사 사례를 쉽게 참고할 수 있는 운영 지식 기반 마련

## 화면 구성

### 1. 챗봇 대화창

사용자가 입력한 질문과 챗봇 답변이 대화형 말풍선 형태로 표시됩니다.

- 사용자 질문은 우측 말풍선으로 표시
- 챗봇 답변은 `하나` 아바타와 함께 좌측 말풍선으로 표시
- 답변은 단순 원문이 아니라 처리 방향 중심의 `통합 처리결과`로 표시
- 검색 전에는 안내 문구가 표시됨

### 2. 질문 입력 영역

담당자가 고객 증상이나 문의 내용을 자연어로 입력하는 영역입니다.

예시:

```text
ERP시스템에 데이터 반영이 안되었는데 무엇을 확인해야 하지?
```

### 3. 유사 질문

답변 하단에는 검색 결과와 관련된 유사 질문이 표시됩니다.

- 최대 5개까지 표시
- 실제 질문 형태의 문장만 후보로 표시
- 가이드성 문구는 후보에서 제외
- 후보를 클릭하면 해당 질문으로 즉시 재검색되고 답변이 갱신됨

### 4. 최근 유사 고객사 사례

오른쪽 영역에는 최근 검색 결과와 관련된 유사 고객사 사례가 표시됩니다.

- 고객사명
- 유사 질문
- 처리결과
- 업무 분류
- 운영구분
- 유사도

담당자는 현재 문의와 비슷한 과거 사례를 참고하여 고객 안내 문구를 보완할 수 있습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 자연어 질문 검색 | 고객 증상이나 문의 내용을 문장 형태로 입력하여 FAQ 검색 |
| 통합 처리결과 생성 | 유사 FAQ 답변을 기반으로 실제 처리 방향 중심의 답변 표시 |
| 유사 질문 후보 | 관련 질문을 답변 하단에 표시하고 클릭 시 즉시 재검색 |
| 최근 유사 사례 | 유사 고객사 질문과 처리내용을 함께 표시 |
| FAQ 보강 데이터 반영 | 엑셀, PPT 자료를 FAQ 데이터로 변환하여 지식 보강 |
| 로컬 FAQ 저장 | 보강된 FAQ 데이터를 서버 로컬 저장소에 저장 |

## 답변 생성 기준

챗봇 답변은 단순히 과거 처리내용을 그대로 보여주는 방식이 아니라, 담당자가 바로 고객에게 안내할 수 있도록 핵심 처리결과 중심으로 정리됩니다.

### ERP 데이터 미반영 문의 예시

질문:

```text
ERP시스템에 데이터 반영이 안되었는데 무엇을 확인해야 하지?
```

답변 방향:

```text
- 통합CMS 프로그램에서 ERP에 반영하려는 데이터가 조회되어 있는지 확인
- 데이터가 조회되지 않으면 최신정보가져오기가 정상 수행되었는지 확인
- 조회 기간, 계좌 조건, 거래 발생 여부를 실제 거래내역 기준으로 재확인
- 통합CMS에서 데이터 조회가 확인되면 ERP 내보내기 또는 수동 전송 후 ERP 화면 반영 여부 확인
- 계속 미반영되면 조회 조건과 오류 화면을 기록해 기술지원팀 접수
```

## FAQ 데이터 분류 기준

FAQ 데이터는 다음 기준으로 분류됩니다.

| 분류 | 설명 |
| --- | --- |
| 회사 | 고객사명 또는 고객사 공통 |
| 업무 | 오류발생, 서버점검, ERP연계, 설치등록, 사용자 교육 등 |
| 운영구분 | 운영, 연계, 개설 |
| 질문 | 고객 문의 또는 담당자 검색 질문 |
| 답변요약 | 고객에게 안내할 처리결과 또는 점검 방향 |
| 상태 | 기본, 등록, 문서 출처 등 |

### 운영구분 자동 분류

- 업무유형이 `설치등록`이면 `개설`
- 업무유형이 `ERP연계`이면 `연계`
- 그 외 업무는 `운영`

## FAQ 보강 데이터

운영 중 확보한 자료를 FAQ 데이터로 추가할 수 있습니다.

지원 자료:

- 활동이력 엑셀
- QNA 정리본 엑셀
- 월간활동실적 엑셀
- 통합CMS 안내/점검 PPT

반영 기준:

- 활동이력: `요청사항`을 질문, `처리내용`을 답변으로 사용
- QNA 정리본: 질문/답변 형태의 셀을 추출하여 FAQ로 변환
- PPT 문서: 슬라이드별 텍스트를 FAQ 보강 자료로 변환
- 중복 FAQ는 제외
- 답변이 비어 있는 항목은 제외

## 운영 가이드

1. 고객 문의 내용을 가능한 한 증상 중심으로 입력합니다.
2. 챗봇 답변의 `통합 처리결과`를 먼저 확인합니다.
3. 답변 하단의 `유사 질문`을 클릭하여 유사 답변을 비교합니다.
4. 오른쪽 `최근 유사 고객사 사례`에서 실제 처리 사례를 참고합니다.
5. 신규 문의나 답변 품질이 낮은 사례는 FAQ 보강 데이터에 추가합니다.

## 보안 및 개인정보 기준

- 원본 업로드 파일은 저장하지 않습니다.
- FAQ 저장 시 질문/답변 중심의 운영 지식만 저장합니다.
- 고객사별 민감정보, 계좌번호, 인증서 정보, 접속정보, 개인정보는 FAQ 답변에 포함하지 않는 것을 원칙으로 합니다.
- 기술지원 접수 시에는 오류 화면, 조회 조건, 발생 시점 등 필요한 점검 정보만 기록합니다.

## 기대 효과

- 고객 문의 응대 시간 단축
- 반복 문의 답변 표준화
- 담당자 간 운영 지식 공유
- 신규 담당자 교육 부담 완화
- 운영 사례 기반 FAQ 자산 축적
