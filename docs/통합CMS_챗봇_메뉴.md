# 통합CMS 챗봇 메뉴

## 메뉴 개요

`통합CMS 챗봇`은 하나은행 통합CMS 운영 중 자주 접수되는 문의, 오류 처리 사례, 사용자 매뉴얼, 기업인터넷뱅킹 FAQ를 기반으로 담당자가 빠르게 답변 방향을 확인할 수 있도록 구성한 FAQ형 업무 지원 메뉴입니다.

고객 질문을 입력하면 질문 의도를 분류하고, 챗봇 화면 안에서 답변을 표시합니다. 답변 하단에는 유사 질문을 제공하여 담당자가 비슷한 문의를 바로 다시 검색할 수 있습니다.

## 메뉴 목적

- 통합CMS 운영 문의에 대한 답변 속도 향상
- 담당자별 답변 편차 축소
- 로그인, 인증서, 이체, ERP연계, 설치등록, Agent/서버, 자금관리 등 반복 문의 대응
- 통합CMS 사용자 매뉴얼과 기업인터넷뱅킹 FAQ를 활용한 안내 범위 확대
- 과거 질문 이력을 기반으로 반복 문의를 빠르게 재검색

## 화면 구성

### 1. 통합CMS 챗봇

메인 화면은 챗봇 대화 형태로 구성합니다.

- 사용자가 입력한 질문은 오른쪽 말풍선으로 표시
- 챗봇 답변은 왼쪽 말풍선으로 표시
- 답변 하단에 답변일시 표시
- 표 형태의 답변은 챗봇 말풍선 안에서 표로 표시
- 하나은행 색상 계열을 적용하여 화면 톤 통일

### 2. 과거 질문

`과거 질문` 영역은 통합CMS 챗봇 오른쪽에 배치합니다.

- 최근 검색한 질문을 누적 표시
- 질문일시 함께 표시
- 과거 질문을 클릭하면 해당 질문으로 즉시 재검색
- 동일 질문은 중복 누적하지 않고 최신 질문일시 기준으로 갱신

### 3. 질문 검색

담당자가 고객 증상 또는 문의 내용을 자연어로 입력하는 영역입니다.

예시:

```text
기업뱅킹 업무별 결재 가능 시간은 어떻게 되나요?
```

```text
ERP시스템에 데이터 반영이 안되었는데 무엇을 확인해야 하지?
```

```text
타기관에서 발급받은 인증서로 로그인해야 하는데 어떻게 해야 하지?
```

### 4. 답변 결과

답변은 단순 원문 나열이 아니라 질문 의도에 맞는 처리 방향 중심으로 표시합니다.

- 직접 답변이 있는 질문은 직접 답변을 우선 표시
- 유사 FAQ 기반 답변은 질문 카테고리에 맞는 항목만 조합
- 질문과 무관한 로그인, 설치, Agent, 스케줄러 답변이 섞이지 않도록 의도별 필터 적용
- 표가 필요한 답변은 표 형태로 표시

### 5. 많이 검색했던 질문들이에요!

답변 하단에는 많이 검색했거나 현재 질문과 유사한 질문을 표시합니다.

- 최대 5건 표시
- 질문 문장만 간결하게 표시
- 클릭 시 해당 질문으로 바로 재검색
- 가이드성 문구는 유사 질문에서 제외

### 6. 같이 질문했던 사례

현재 질문과 유사한 과거 고객사 사례를 별도 영역으로 표시합니다.

- 고객사명
- 질문
- 처리결과
- 업무 분류
- 운영구분
- 유사도

담당자는 실제 처리 사례를 참고하여 고객 안내 문구를 보완할 수 있습니다.

## 질문 의도별 답변 기준

### ERP 데이터 미반영

```text
- 통합CMS 프로그램에서 ERP에 반영하려는 데이터가 조회되어 있는지 확인
- 데이터가 조회되지 않으면 최신정보가져오기가 정상 수행되었는지 확인
- 통합CMS에서 데이터 조회가 확인되면 ERP 내보내기 또는 수동 전송 후 ERP 화면 반영 여부 확인
```

### 타행계좌 이체

```text
- 타행계좌는 통합CMS에서 이체가 불가합니다.
- 통합CMS 이체는 하나은행 출금계좌로 등록된 계좌 기준으로 가능합니다.
- 이체가 되지 않으면 출금계좌 등록상태, 이체권한, 결재선, 이체한도 설정을 확인합니다.
```

### 대량이체/급여이체

```text
- 대량이체는 한 번에 최대 2,500건까지 가능합니다.
- 급여이체도 한 번에 최대 2,500건까지 가능합니다.
- 2,500건보다 많은 이체가 필요하면 단건출금대량이체 메뉴를 이용해야 합니다.
```

### 타기관 인증서 등록

```text
- 다른 은행 또는 기관에서 발급받은 공동인증서도 하나은행 기업뱅킹에서 사용할 수 있습니다.
- 사용 전 [인증센터 > 다른은행 · 기관 인증서 등록/해제 > 다른은행/기관 인증서 등록] 메뉴에서 등록해야 합니다.
- 등록 시 사업자 유형이 법인사업자/개인사업자 중 올바르게 선택되어 있는지 확인합니다.
```

## FAQ 보강 데이터 관리

운영 중 수집한 자료는 FAQ 보강 데이터로 반영할 수 있습니다.

지원 자료:

- 활동이력 엑셀
- QNA 정리본 엑셀
- 월간활동실적 엑셀
- 통합CMS 사용자 매뉴얼 PPT/PPTX
- 기업인터넷뱅킹 FAQ 기반 데이터

반영 기준:

- 요청사항 또는 질문은 `질문`으로 사용
- 처리내용 또는 답변은 `답변요약`으로 사용
- 민감정보는 제외
- 중복 질문은 제외
- 원본 파일은 저장하지 않고 FAQ 데이터만 로컬 저장

## 운영 가이드

1. 고객 질문은 가능한 한 실제 증상 중심으로 입력합니다.
2. 답변이 맞지 않으면 많이 검색했던 질문에서 유사 질문을 선택해 재검색합니다.
3. 답변 하단의 같이 질문했던 사례를 참고하여 실제 고객 안내 문구를 보완합니다.
4. 새로운 질문이 반복되면 QNA 양식 또는 FAQ 보강 데이터로 추가합니다.
5. 계좌번호, 인증서 정보, 개인정보, 접속정보 등 민감정보는 FAQ 답변에 포함하지 않습니다.

- 반복 문의 대응 시간 단축
- 담당자별 답변 품질 표준화
- 신규 담당자 교육 부담 완화
- 고객 문의와 운영 사례 기반 FAQ 자산화
- 통합CMS 운영 지식의 지속적인 축적
